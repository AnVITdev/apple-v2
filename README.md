## 🌟 Tính Năng Nổi Bật

- **Global Navigation Bar**: Thanh điều hướng chuẩn phong cách Apple với hiệu ứng mờ kính (Frosted Glass / Backdrop Blur) và đầy đủ các danh mục sản phẩm.
- **Hero Showcase**:
  - **iPhone 16 Pro**: Giới thiệu khung Titan Sa Mạc, tính năng Apple Intelligence độc quyền.
  - **iPhone 16**: Màu sắc tươi mới, phong cách trẻ trung năng động.
  - **Apple Watch Series 10**: Thiết kế siêu mỏng cùng màn hình hiển thị lớn.
- **Bento Grid Sản Phẩm**: Lưới hiển thị 2x2 gồm MacBook Air M3, iPad Air M2, AirPods 4 và chương trình Apple Trade In.
- **Tối Ưu Giao Diện**: Hỗ trợ hiển thị mượt mà trên nhiều kích thước màn hình (Desktop, Tablet, Mobile).
- **Trọng lượng siêu nhẹ**: Sử dụng CSS thuần, không cần build nặng nề, khởi chạy tức thì.

## 🚀 Hướng Dẫn Cài Đặt & Chạy

### Yêu cầu tiên quyết:
- Đã cài đặt [Node.js](https://nodejs.org/) (khuyến nghị phiên bản 16 trở lên).

### Bước 1: Clone dự án
```bash
git clone https://github.com/<tai-khoan-cua-ban>/apple-clone.git
cd apple-clone
```

### Bước 2: Chạy Website

#### Cách 1: Sử dụng npm script
```bash
npm start
```

#### Cách 2: Sử dụng Node.js trực tiếp
```bash
node server.js
```

#### Cách 3: Click đúp (Dành cho Windows)
Chỉ cần nhấp đúp vào file `start.bat`.
